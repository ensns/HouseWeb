# HouseWeb — сайт-презентація будинку

Односторінковий сайт для продажу приватного будинку. Без збірки, без залежностей:
три файли (`index.html`, `styles.css`, `main.js`) — відкриваються у браузері як є
і публікуються на GitHub Pages простим `git push`.

```
HouseWeb/
├── index.html                  ← весь текст сайту
├── assets/
│   ├── css/styles.css          ← кольори й типографіка (змінні на початку файлу)
│   ├── js/photos.js            ← ⭐ ФОТО: єдиний файл для заміни знімків
│   ├── js/main.js              ← галерея, лайтбокс, форма (CONFIG угорі)
│   └── img/
│       ├── favicon.svg
│       └── plans/floor-1.svg   ← схеми поверхів
└── scripts/fetch-placeholders.ps1
```

---

## 1. Як подивитись локально

Достатньо двічі клацнути `index.html`. Якщо хочете, щоб усе працювало
точно як на сервері — підніміть локальний сервер:

```bash
python -m http.server 8000
```

Далі відкрийте <http://localhost:8000>.

---

## 2. Як замінити тимчасові фото на справжні

Зараз усі знімки — випадкові заглушки з picsum.photos. Порядок заміни:

1. Складіть справжні фото у теку `assets/img/` (JPEG, ~2000 px по довгій
   стороні, до 500 КБ кожне).
2. Відкрийте `assets/js/photos.js` — це єдиний файл, який треба редагувати.
3. Замініть `ph('hw-g01', 1600, 1100)` на шлях до файлу:

```js
{ src: 'assets/img/fasad-01.jpg', tag: 'exterior', size: 'wide', caption: 'Головний фасад' },
```

Що означають поля:

| Поле      | Призначення                                                              |
|-----------|--------------------------------------------------------------------------|
| `src`     | шлях до фото                                                             |
| `tag`     | категорія для фільтра: `exterior` `living` `kitchen` `bedroom` `bath` `plot` |
| `size`    | `wide` — на дві колонки, `tall` — на два рядки, без поля — звичайна клітинка |
| `caption` | підпис, що з'являється при наведенні й у повноекранному перегляді        |

Рядків у масиві `gallery` може бути скільки завгодно — сітка підлаштується.

Окремо замініть:
* `hero` — головне фото на весь екран (горизонтальне, найкращий кадр фасаду);
* `about-1` — вертикальне фото інтер'єру, `about-2` — горизонтальне;
* у `index.html` тег `og:image` — фото 1200×630 для прев'ю в месенджерах.

Коли всі фото стануть локальними, приберіть з початку `photos.js` рядок
з `const ph = ...`.

## 2а. Варіанти оформлення (тимчасово, на час вибору)

Той самий сайт із тим самим текстом і фото можна подивитися у трьох оформленнях:

| Адреса | Варіант |
|--------|---------|
| `/` | **Класика** — світлий преміум-мінімалізм, Cormorant Garamond |
| `/?theme=night` | **Ніч** — темна галерейна подача, золоті акценти |
| `/?theme=warm` | **Затишок** — тепла скандинавська, скруглення, Inter у заголовках |

Додайте `?compare=1`, щоб унизу з'явився перемикач між усіма трьома.

Звичайний відвідувач за адресою без параметрів бачить лише «Класику» —
перемикача немає, зайвих файлів не завантажується.

**Коли варіант обрано**, приберіть три речі:

1. блок «ПОРІВНЯННЯ ВАРІАНТІВ ОФОРМЛЕННЯ» у `<head>` файлу `index.html`;
2. блок «9. ПЕРЕМИКАЧ ВАРІАНТІВ» наприкінці `assets/js/main.js`;
3. непотрібні файли `assets/css/theme-night.css` і `assets/css/theme-warm.css`.

Якщо обрали не «Класику» — перенесіть вміст потрібного `theme-*.css`
на початок `assets/css/styles.css` (замінивши блок `:root`), і теж приберіть
все перелічене вище.

## 3. Як замінити текст

Увесь текст лежить прямо в `index.html` — шукайте потрібний блок за
коментарями-роздільниками (`ГОЛОВНИЙ ЕКРАН`, `ПРО БУДИНОК`, `ЛОКАЦІЯ` тощо).

Обов'язково змініть:

* адресу, ціну й цифри — у блоках `hero` та `facts`;
* характеристики — у секції `specs`;
* координати мапи: у `<iframe>` замініть `marker=50.3167%2C30.5167` на свої,
  а також `bbox` (чотири числа: захід, південь, схід, північ);
* ім'я та телефон власника — у секції `contact`;
* `<title>` і `<meta name="description">` у `<head>` — це те, що бачить Google.

Назви кімнат і площі у розділі «Планування» — у `photos.js`, масив `plans`.
Схеми поверхів (`assets/img/plans/*.svg`) намальовані вручну як заглушки —
замініть їх на скан технічного паспорта, вказавши шлях у тому ж масиві.

## 4. Форма заявки

За замовчуванням форма відкриває поштову програму відвідувача.
Вкажіть свою адресу у `assets/js/main.js`:

```js
const CONFIG = {
  ownerEmail: 'your.mail@example.com',
  formEndpoint: ''
};
```

Щоб заявки приходили на пошту автоматично (без відкриття поштової програми),
зареєструйте безкоштовну форму на [Formspree](https://formspree.io) або
[Getform](https://getform.io) і вставте отриману адресу у `formEndpoint`.
GitHub Pages не має серверної частини, тому це єдиний спосіб.

## 5. Публікація на GitHub Pages

```bash
git add -A
git commit -m "Сайт-презентація будинку"
git branch -M main
git remote add origin https://github.com/ensns/HouseWeb.git
git push -u origin main
```

Далі у репозиторії: **Settings → Pages → Source: Deploy from a branch →
Branch: `main`, папка `/ (root)` → Save.**

Через хвилину сайт буде за адресою `https://ensns.github.io/HouseWeb/`.
Кожен наступний `git push` оновлює його автоматично.

### Власний домен

Купіть домен, у налаштуваннях DNS додайте чотири `A`-записи на
`185.199.108.153`, `185.199.109.153`, `185.199.110.153`, `185.199.111.153`,
далі впишіть домен у **Settings → Pages → Custom domain** і поставте
галочку **Enforce HTTPS**. Сертифікат GitHub видає безкоштовно.

## 6. Дрібниці

* Кольори й шрифти — змінні на початку `styles.css` (`--accent`, `--ink`, `--bg`).
* Сайт адаптивний: перевірено на 375 px, 768 px і 1440 px.
* Працює клавіатура: `Esc` закриває фото, `←` / `→` гортають галерею.
* `scripts/fetch-placeholders.ps1` завантажує тимчасові фото на диск,
  якщо потрібно показати сайт без інтернету.
